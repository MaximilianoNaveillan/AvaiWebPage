# INC-005 - Contenido Duplicado En Servicios Del Home

Prioridad: Media
Estado: Pendiente

## Problema

En `src/sections/Home/Servicios.astro` hay dos tarjetas con el mismo titulo `Analitica Real-time` y texto muy similar.

## Impacto

- La oferta de servicios parece incompleta o repetida.
- Reduce claridad comercial.
- Puede generar desconfianza en una landing orientada a precision tecnica.

## Solucion Sugerida

- Definir una cuarta categoria real de servicio.
- Alinear icono, titulo y descripcion.
- Revisar que cada tarjeta tenga un beneficio diferente.

## Criterios De Aceptacion

- Las cuatro tarjetas del home tienen titulos distintos.
- Cada descripcion comunica un valor unico.
- El contenido queda alineado con la pagina de servicios.
