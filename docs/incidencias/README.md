# Incidencias AVAI

Este directorio documenta incidencias, mejoras tecnicas y nuevas funcionalidades pendientes para el sitio AVAI.

## Prioridad

- Alta: bloquea una funcionalidad importante, conversion, SEO base o estabilidad.
- Media: mejora mantenibilidad, accesibilidad, performance o experiencia de usuario.
- Baja: ajuste menor o deuda tecnica sin impacto inmediato.

## Estados

- Pendiente: documentada y sin implementar.
- En progreso: existe trabajo activo.
- Resuelta: implementada y verificada.
- Cancelada: ya no aplica.

## Orden Recomendado

1. Implementar `INC-001` porque agrega una nueva seccion estrategica del sitio.
2. Resolver `INC-002` para que el blog y las paginas existentes salgan con metadata correcta.
3. Resolver `INC-003` e `INC-004` antes de ampliar interacciones.
4. Continuar con accesibilidad, performance y limpieza de contenido.
